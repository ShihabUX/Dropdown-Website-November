# DROPDOWN DIGITAL
## Visual Identity & Campaign Design System

**Purpose:** This is the reusable visual direction for all future Dropdown Digital creative. Attach or paste this file into any design brief so different designers and AI image models produce work that feels like **one premium brand**, even when concepts change.

**Brand standard:** **Premium. Intelligent. Contemporary. Precise. Confident.**

**Creative principle:** Strong thinking, strong typography, and deliberate space. Every visual element must earn its place.

> **Non-negotiable:** Consistency does **not** mean repeating one poster layout. Maintain the visual grammar while changing the idea, geometry and composition for each message.

---

## 01 — Brand DNA

| Dimension | Direction |
|---|---|
| Perception | A sophisticated creative and digital growth partner; never a bargain-template agency |
| Visual references | Swiss editorial graphics, contemporary digital product design, restrained architectural forms |
| Personality | Assured, strategic, clear, design-conscious; not flashy or loud |
| Look and feel | Near-black typography, clean almost-white surfaces, precise electric-lime interventions |
| Communication | One sharp idea per asset, with a short human supporting line |
| Visual rhythm | Heavy typography + spacious margins + a single disciplined conceptual visual |
| Desired reaction | “This company looks thoughtful, capable and premium.” |

**Guiding phrase:** *More than ordinary.* This is a positioning idea, **not** a mandatory headline or footer on every asset.

## 02 — Color System: Exact Brand Tokens

### Core palette — lock these values

| Token | Hex | Usage |
|---|---|---|
| **Lime / Brand Accent** | **`#B9F34E`** | High-priority highlights, thin strokes, transition paths, dots and selected fields |
| **White / Main Canvas** | **`#FEFEFE`** | Default light backgrounds and whitespace |
| **Near Black / Ink** | **`#111111`** | Primary text, dark panels and dark-background posters |

### Supporting neutrals — non-brand utility colors

| Token | Hex | Usage |
|---|---|---|
| Charcoal | `#222222` | Black-on-black depth, dark UI planes |
| Muted gray | `#666666` | Secondary text where appropriate |
| Hairline gray | `#DADADA` | Grids, fine rules, unobtrusive UI details |
| Pale gray | `#F0F0F0` | Interface panels and abstract component surfaces |

**Color priority:** `#FEFEFE` + `#111111` create the structure; `#B9F34E` provides the moment of distinction.

**Recommended visual balance:** Roughly 75–90% neutral / 10–25% accent and special surfaces, depending on composition. In light posters, lime usually occupies **5–15%** of the frame. For one dramatic hero shape, up to about **20%** may work. These are art-direction guidelines, not a measurement mandate.

**Dark variation:** Use `#111111` for the dominant background, `#FEFEFE` for display text, and `#B9F34E` sparingly for the most important accent. Fine chart grids may use low-opacity grays.

**Important reference note:** Some AI-generated reference posters have slightly creamy white pixels. That warmth is a rendering effect, **not** a replacement for the approved background `#FEFEFE`. A subtle off-white photographic surface is allowed *inside* an object or scene, but do not quietly change the brand's master color tokens.

**Avoid:** Other neon colors, rainbow gradients, gold, bright blue, excessive green glow, multicolor icons, and large saturated gradients that fight the headline.

## 03 — Typography System

### Type personality

Use a **modern, geometric/neo-grotesk sans serif** with strong display weights, clean counters, and excellent spacing.

**Preferred look:** Satoshi, Neue Montreal, Helvetica Now Display.

**Practical alternatives:** Inter Tight, Inter, Manrope, or a similarly refined sans-serif. Choose a legitimate licensed/available font. Do not fake font weight by stretching letters.

| Level | Weight | Case | Typical behavior |
|---|---|---|---|
| Display headline | ExtraBold/Black, 800–900 | **UPPERCASE** | Extremely clear, tight but not touching, 3–5 deliberate lines |
| Emphasis word | Bold/Black, sometimes italic | Usually uppercase | One highlighted word/phrase, not every word |
| Supporting sentence | Regular/Medium, 400–500 | Sentence case | Short, conversational, high legibility |
| Eyebrow / Suite name | Medium/Semibold, 500–650 | Uppercase | Small, generous tracking, unintrusive |
| Micro-labels | Medium/Semibold | Sentence case / uppercase as needed | Only when essential to the concept |

### Typographic ratios — 1122 × 1402 master poster

These are **starting values** for a raster canvas, not fixed requirements:

| Element | Suggested size | Line-height | Tracking |
|---|---:|---:|---|
| Headline | 86–122 px | 0.92–1.02 | -1.5% to -3% |
| Supporting text | 31–41 px | 1.14–1.28 | 0% to -1% |
| Suite / eyebrow | 18–26 px | 1.25–1.4 | +10% to +20% |
| Labels | 20–28 px | 1.15–1.3 | 0% to +2% |

For other sizes, **scale proportionally and inspect optically**. The headline must remain legible on a phone, not just at full desktop zoom.

### Rules

1. **Keep text proportions natural.** Never horizontally squeeze, stretch, warp, or compress a headline to fill space.
2. Use **manual line breaks** for a strong, readable rhythm; don't rely on arbitrary wrapping.
3. Avoid orphaned tiny words and awkward line endings. Give each line enough space to breathe.
4. Prefer **flush-left alignment**. Centering is an intentional exception, not the default.
5. Emphasize **one** meaningful phrase using lime, italic type, an underline, a lime plane, or a dot.
6. Make contrast unambiguous: near-black on off-white, or off-white on near-black. Lime is usually a highlight, not body-text color.
7. Use **only two typographic families at most**; usually one excellent family is stronger.
8. Don't decorate with fake microtype or unreadable filler captions.

**Example headline hierarchy:**

```text
RUNNING
ADS ISN'T
MANAGING     ← near-black text on a lime highlight
ADS.

30 days of strategy, execution
and ongoing optimization.
```

**Note:** The highlighted word is a concept-specific device, not a mandatory green strip in every poster.

## 04 — Layout, Margins & Whitespace

### Master social canvas

- **Preferred master:** **1122 × 1402 px** (mobile-focused, approximately 4:5).
- **Standard feed alternate:** **1080 × 1350 px** (exact 4:5).
- Keep artwork inside the target ratio; **crop and recomposite — never distort the entire image**.
- Export clear high-resolution PNG or high-quality JPEG as required by the platform.

### Grid and safety

| Constraint | Rule | At 1122 × 1402 |
|---|---|---|
| Outer left/right margin | ~7–9% of width | ~79–101 px |
| Top/bottom content safety | ~5–8% of height | ~70–112 px |
| Primary text column | ~75–90% of usable width | Flexible by headline |
| Major section separation | Clearly visible, not crammed | Often 50–110 px |
| Minor element gap | Built on a consistent scale | 12 / 20 / 32 / 48 px |
| Fine rule/line | Hairline only | Roughly 1–2 px at master size |

Treat these as **optical guidelines**, not a rigid UI framework. Preserve enough room around every text block and object.

### Intentional logo / brand-signature reserve

**Default for AI artwork:** Do **not** create or hallucinate a logo, wordmark, or brand icon. Use the actual approved logo only if provided and expressly requested.

When future branding may be added in post-production:

- Reserve a calm **blank area at the top-left or top-right**, preferably **140–240 px high** (adjust to composition).
- Keep that space free of text, lime shapes, grids with strong lines, and busy 3D elements.
- Logo zone should look naturally designed, **not** like an obvious empty placeholder box.
- Never put a fake `LOGO HERE` caption in the final artwork.
- If inserting the supplied real logo, align it to the existing text grid and keep generous clear space.

**Whitespace is a brand asset.** Do not fill it with meaningless bars, symbols, charts, textures, or microcopy.

## 05 — Approved Design Grammar

The attached chosen references establish **three complementary modes**:

### A. Strategic Dark — “Running Ads Isn't Managing Ads”

- Full `#111111` background.
- Oversized white uppercase headline; key strategic word on a restrained lime plane.
- Small, quiet supporting sentence below headline.
- Fine analytical grid, deliberate data-like line and a few nodes in lower area.
- Strategic and expert; feels precise rather than aggressive.
- **Never present decorative lines as real results**. No fabricated ROAS, revenue or performance metrics.

### B. Editorial Light + Conceptual Product Journey — “The Click Is Not the Finish Line”

- Large clean upper whitespace that can also support future logo placement.
- Heavy left-aligned headline; one lime-highlighted payoff phrase.
- One concise supporting sentence.
- Lower portion has a **simple 2.5D conceptual system**: connected ad creative → storefront → checkout.
- Lime works as a continuous visual connector; neutral structures carry the forms.
- Strong conceptual storytelling without stock photography or platform logos.

### C. Architectural Growth — “Build. Launch. Grow.”

- Clean light upper section with an assertive three-part headline.
- Small, tracked suite descriptor.
- Large **black/white/lime interlocking architectural forms** in the lower half.
- Each major layer represents a real service or stage, not generic decoration.
- Controlled dimensionality; no glossy sci-fi treatment.

### Elements worth reusing (choose selectively)

- Bold typographic pacing.
- Thin technical grids and fine alignment guides.
- A single lime highlight **bar, dot, underscore, ribbon, or plane**.
- Large negative space and deliberate asymmetry.
- Simple 2.5D interface cards with realistic hierarchy, not dense fake dashboards.
- Monolithic, layered or stepped forms that visualize systems and progression.
- One crisp conceptual object or abstract scene, subordinate to the headline.

### Elements not to repeat mechanically

Do **not** place the same neon stripe, rising line chart, corner swoosh, triple-card stack or lime dot in every post. Consistency comes from **palette, type, whitespace, image treatment, geometry and restraint**—not identical decorations.

## 06 — Image & Graphic Construction

### Composition formula

**One idea → one headline → one visual metaphor → one support line.**

Aim for a reading sequence:

1. **Headline** — understood instantly.
2. **Emphasis** — one strategic lime moment.
3. **Visual concept** — adds meaning, not clutter.
4. **Supporting copy** — explains what is offered or why it matters.
5. **Logo** — only if supplied/approved; otherwise preserve a useful blank zone.

### Dimensionality

- Prefer **flat vector geometry or restrained 2.5D scenes**.
- Mild architectural depth and **soft, localized shadows** are allowed.
- Keep surfaces matte or satin; avoid shiny plastic and glassmorphism as a default.
- UI cards should look like simplified product interfaces, not screenshots pretending to be real data.
- If a physical product is used inside a mock storefront, it must support the concept and not imply a real client project without permission.

### Data visuals

- Use graphs only when they add clear meaning.
- With no source data: graphs must be obviously **conceptual**, without numbers, fabricated results, client names or endorsements.
- Avoid always-upward arrows as a shortcut for “growth.”

## 07 — Copy and Content Grammar

**Headline:** Bold, specific, provocative or insight-led; usually **4–10 words**. Natural language wins over generic slogans.

**Supporting text:** One short sentence; ideally **8–20 words**. Explain the practical benefit without overpromising.

**Optional micro-label:** A campaign or package name in small uppercase tracking. Not required on every poster.

### Good language patterns

- “RUNNING ADS ISN'T MANAGING ADS.”
- “THE CLICK IS NOT THE FINISH LINE.”
- “BUILD. LAUNCH. GROW.”
- “GOOD CONTENT STARTS WITH A PLAN.”

### Avoid

- Empty hype: “Unlock limitless potential,” “Revolutionize your digital journey,” “Skyrocket your sales.”
- Fake social proof, rankings, guaranteed returns or invented success rates.
- Overlong paragraphs, five benefits in one asset, decorative CTAs that look like actual interactive controls.
- Price, discounts or limited-time claims unless a specific campaign brief explicitly approves them.

**Approved subject areas** include e-commerce development, paid advertising strategy/management, content strategy, creative direction, brand identity, web experiences and business systems. **Service scope and promises must always be checked against the current offer before publishing.**

## 08 — Designing Different Material Types

| Format | Direction |
|---|---|
| Facebook / Instagram feed poster | 4:5, commanding display, one concept, generous outer safety |
| Mobile banner | Preserve hierarchy; make logo-reserve area and top copy readable without zooming |
| Desktop website banner | Reflow into a horizontal editorial composition, not a stretched vertical poster |
| Carousel | One idea per slide; persistent grid/color/type, new visual rhythm slide to slide |
| Story / Reel cover | Use central safe space; account for UI overlays and cropped previews |
| Proposal / pitch deck | Same palette and typography; more whitespace, restrained charts and clear evidence labels |
| Social cover | Fewest possible words; preserve readability across mobile cropping |
| Printed materials | Same identity; set typography and bleed based on actual print dimensions |

**Color consistency across formats matters more than identical layouts.**

## 09 — Prompt Protocol for Future AI Designers

Include the following block in a creative request **together with this design system**.

### Reusable master prompt

```text
Act as a senior creative director and editorial graphic designer for
Dropdown Digital, a premium digital agency.

Create ONE finished [FORMAT] at [EXACT DIMENSIONS].

CAMPAIGN IDEA:
[Describe the new strategic concept and what the audience should understand.]

EXACT HEADLINE:
[Insert approved exact words.]

SUPPORTING COPY:
[Insert approved exact words.]

OPTIONAL LABEL:
[Insert approved small campaign descriptor, or "none".]

LOGO INSTRUCTION:
["No logo; leave a naturally empty logo-safe region at top-left" OR
 "Use only the supplied real logo, with generous clear space".]

FOLLOW THE ATTACHED "DROPDOWN DIGITAL — VISUAL IDENTITY & CAMPAIGN
DESIGN SYSTEM".

LOCK BRAND COLORS:
#B9F34E (electric lime), #FEFEFE (primary white), #111111 (near-black).

DESIGN GRAMMAR:
- Premium Swiss editorial design, confident neo-grotesk display typography.
- Clean left-aligned typographic hierarchy, proportional letterforms,
  deliberate line breaks, strong negative space and precise alignment.
- One clear conceptual visual metaphor, not generic agency clip art.
- Highlight only the central phrase/idea with lime.
- Keep artwork cohesive with earlier Dropdown Digital campaign posters,
  but create a genuinely fresh composition.
- Calm neutrals, matte surfaces, restrained 2.5D only if conceptually useful.
- Maintain adequate safe margins and an intentional logo zone if requested.
- Keep all English wording exact and spelled correctly.

AVOID:
- Logo hallucinations, fake metrics, fake client work, prices not authorized.
- Squeezed type, clutter, tiny filler text, excessive gradients, glassmorphism,
  generic growth arrows, stock-business photos and excessive shadows.
- Repeating the same layout or graphic motif just to match previous assets.

QUALITY BAR:
Deliver an internationally competitive premium-agency campaign piece.
The headline must read clearly at mobile size. Maintain exact proportions;
do not stretch the design to meet a target dimension.
```

### Fields to change for each design

- Format/dimensions and placement context.
- Unique idea and approved exact copy.
- Light mode or dark mode.
- Chosen visual metaphor (system, progression, architecture, calendar, abstract data, etc.).
- Logo instruction and whether a real source image is supplied.

### Fields to keep fixed

- Three core hex values.
- Premium typography behavior and physical letter proportions.
- Generous whitespace and strong grid discipline.
- Single conceptual message and single high-priority accent.
- No fake performance claims or unauthorized branding.

## 10 — Production & Quality Assurance Checklist

**Before approving any creative, verify:**

- [ ] Uses the **exact** approved brand colors: `#B9F34E`, `#FEFEFE`, `#111111`.
- [ ] Feels premium, calm, contemporary and strategically composed.
- [ ] The headline has a clear hierarchy, intentional line breaks and natural letter proportions.
- [ ] English copy matches the approved text **exactly** (including punctuation).
- [ ] No accidental lettering distortions, overlapping letters or AI-generated gibberish.
- [ ] Supporting copy reads comfortably on an actual mobile screen.
- [ ] The lime accent is deliberate, not sprayed everywhere.
- [ ] White space has been preserved; no unnecessary icons or filler.
- [ ] Logo has not been hallucinated; approved logo-space instruction is followed.
- [ ] Visual concept supports the actual message and business offer.
- [ ] UI, charts and mockups do not present fictional results as fact.
- [ ] No visual copy/paste of previous campaign layouts.
- [ ] Key elements are safely within the intended crop and platform overlays.
- [ ] Export is crisp at the requested canvas size; there is no stretching.

**AI-generation workflow:** Generate concept → inspect at phone scale → check spelling and geometry → correct exact colors → adjust kerning/crop as needed → export final. If an image model cannot render exact text or hex colors reliably, finish those details in a design editor before publication.

## 11 — Final Creative Filter

Ask these five questions:

1. **Could an international premium design studio publish this?**
2. **Would it still look like Dropdown Digital with the logo removed?**
3. **Does every visual element clarify the idea or improve hierarchy?**
4. **Is the typography beautiful and legible rather than merely huge?**
5. **Does this add a fresh idea to the campaign without breaking its identity?**

If any answer is **no**, refine the piece before publishing.

**One-sentence design summary:**

> **Dropdown Digital is bold type, intelligent restraint, near-black confidence, almost-white breathing room, and one precise electric-lime intervention.**
